# Uni20 artwork

The [Uni20 logo](uni20-yushan-ridge.png) depicts Taiwan’s Yushan (Jade Mountain) as a tensor network viewed from the North Peak. The [Uni20-dev avatar](uni20-dev-yushan-avatar.png) uses the same mountain and bonds in a square crop.

The artwork adapts Kailing3’s [photograph of Yushan](https://commons.wikimedia.org/wiki/File:Mount_Yu_Shan_-_Taiwan.jpg) into a faceted ridge with tensor nodes and bonds. Both PNGs are distributed under [Creative Commons Attribution-ShareAlike 3.0](https://creativecommons.org/licenses/by-sa/3.0/).
